# Backend Directory

This directory is reserved for any backend services if needed. 

Currently, the application uses:
- **Frontend**: Next.js (handling API routes if necessary)
- **Data**: Polymarket Gamma API (called directly from frontend)
- **Smart Contracts**: Monad Testnet (interacted with via frontend)

If you need to add a custom backend (e.g., for indexing events or managing user data off-chain), you can initialize a Node.js project here.
